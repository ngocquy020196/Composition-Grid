Composition Grid: 삼분할 법칙, 황금 비율 등

최종 업데이트: March 31, 2026

개요

Composition Grid는 웹 전반의 이미지와 영상 위에 구도 그리드(삼분할 법칙, 황금 비율, 피보나치 나선, 황금 삼각형, 오분할, 중앙 십자선)를 오버레이하는 Chrome, Microsoft Edge, Firefox용 브라우저 확장 프로그램입니다. 당사는 귀하의 개인정보 보호를 위해 최선을 다하고 있습니다.

데이터 수집

당사는 어떠한 개인 데이터도 수집, 저장 또는 전송하지 않습니다.

본 확장 프로그램은:

  • 브라우저의 storage.sync API를 사용하여 귀하의 설정(그리드 유형, 색상, 크기, 언어, 사이트 필터 목록)을 로컬에 저장합니다
  • 사이트 필터 설정에 따라 컨텍스트 메뉴를 표시하거나 숨기기 위해 활성 탭의 URL을 로컬에서 읽습니다
  • 전적으로 귀하의 기기에서 실행됩니다
  • 검색 기록을 수집하지 않습니다
  • 개인 정보를 수집하지 않습니다
  • 사용자 행동을 추적하지 않습니다
  • 외부 서버로 데이터를 전송하지 않습니다
  • 쿠키나 분석 도구를 사용하지 않습니다

권한

권한 용도
storage 귀하의 그리드 설정과 사이트 필터 목록을 로컬에 저장합니다
contextMenus 이미지에서 그리드를 켜고 끌 수 있는 마우스 오른쪽 클릭 메뉴 옵션을 추가합니다
tabs 차단했거나 허용하지 않은 사이트에서 컨텍스트 메뉴를 숨기기 위해 활성 탭의 URL을 읽습니다
<all_urls> (content script) 모든 웹사이트의 이미지 위에 그리드를 오버레이합니다

제3자 서비스

본 확장 프로그램은 어떠한 제3자 서비스, API 또는 분석 도구도 사용하지 않습니다.
